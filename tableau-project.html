Data Analytics with Tableau

Description

Developed interactive dashboards using Tableau to analyze and visualize complex datasets in a clear and meaningful way. Collected data from Excel and SQL sources and performed data cleaning to ensure accuracy and consistency. Created charts, graphs, and KPI indicators to monitor trends and performance. Implemented filters and drill-down features to make dashboards dynamic and easy to explore. Delivered actionable insights to support data-driven decision-making.
