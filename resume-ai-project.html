AI-Powered Resume Screening and Candidate Ranking System with Multiple Resumes Analysis and PDF Report Generator

Description

Developed an intelligent recruitment system that automates resume screening using Artificial Intelligence and Natural Language Processing. The system analyzes multiple resumes and extracts key details like skills, education, and experience. It compares candidate profiles with job descriptions using techniques like TF-IDF and cosine similarity to generate match scores. Based on these scores, candidates are ranked automatically to help recruiters identify the best fit. The system also generates detailed PDF reports and provides a dashboard for easy analysis and decision-making.
